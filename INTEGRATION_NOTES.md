
## Integration Testing

Frontend, backend, REST APIs, database integration, and Temporal workflow integration are configured on the integration-testing branch.

### Current Integration Status

- Frontend: Vite/React
- Backend: Spring Boot
- API: REST endpoints
- Database: MySQL
- Workflow: Temporal
- Branch: goutham-integration-testing

The integration branch is used for testing the interaction between the frontend,
backend APIs, database layer, and Temporal workflow components.
